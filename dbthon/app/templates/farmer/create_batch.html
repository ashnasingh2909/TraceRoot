Creating a HARVEST batch inserts into the batches

  • batch_type = 'HARVEST'
  • farm_id NOT NULL (direct link to source farm)
  • quantity_kg = initial_quantity_kg (full quantity available)
  • status = 'ACTIVE' (ready for processing/inspection)

This demonstrates INSERT with FK constraints - the farm_id must reference an existing farm.
